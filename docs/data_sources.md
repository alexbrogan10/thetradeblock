# Data Sources

## Demo configuration (default, `DEMO_MODE=true`)

All data is **synthetic**, generated by `scripts/generate_demo_data.py`
with a fixed random seed. See `data/raw/README.md` for the full
per-file breakdown of fields, generation method, and limitations.

- Team names/abbreviations/conferences/divisions: public information
  about NFL league structure.
- Players, statistics, contracts: entirely fictional, randomly
  generated. Not real people, not real performance data.
- Draft picks: synthetic ownership across three draft years with
  simulated historical pick trades.
- Historical trades: synthetic trades (2021-2025) reusing the same
  synthetic player pool, with player age/position *snapshotted at the
  time of the trade* rather than using current-day values. Outcome
  notes are short, neutral, illustrative text — not a claim that any
  historical trade predicts a future one (Section 24).

**This demo dataset must never be presented as real NFL data**, per
product rule (Section 56, #20) and the in-app "DEMO DATA" banner.

## Replacing demo data with a real/licensed dataset

1. Set `DEMO_MODE=false` in `.env`.
2. Point `scripts/seed_demo_data.py` (or a new loader following the same
   interface) at CSVs/an API matching the column layout documented in
   `data/raw/README.md`.
3. No backend analytics or frontend code changes are required — the
   ingestion layer is intentionally decoupled from the analytics layer
   (see `docs/architecture.md`).

## What this project does not claim

- No proprietary NFL data (Next Gen Stats, PFF grades, actual contract
  filings, etc.) is bundled, scraped, or reproduced.
- No web scraping is performed by any script in this repository.
- This is an independent project, not affiliated with the NFL or any
  team.
