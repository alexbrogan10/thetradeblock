# Raw Data — DEMO DATA, NOT OFFICIAL NFL DATA

This directory holds the inputs consumed by `scripts/seed_demo_data.py`.
In the packaged demo configuration, every file here is **synthetic data
generated by `scripts/generate_demo_data.py`** using a fixed random seed.

## Source

- **Team names, abbreviations, conferences, divisions** (`teams.csv`):
  public information about the current structure of the league. Not
  proprietary. Not sourced from any NFL API or licensed data feed.
- **Players, statistics, contracts** (`players.csv`, `player_stats.csv`,
  `contracts.csv`): **entirely fictional**. Names are randomly generated
  from generic first/last-name pools and are not intended to represent
  any real person. Statistics and contract figures are drawn from
  randomized-but-realistic ranges, not observed or reported data.
- **Draft picks** (`draft_picks.csv`): synthetic draft-pick ownership
  across three draft years, including a simulated set of already-executed
  pick trades so the Draft Capital dashboard has realistic variance
  across teams.

## Collection Date

Generated 2026-09-09 via a deterministic script (seed `20260101`). Re-running
`scripts/generate_demo_data.py` with the same seed reproduces identical data.

## License

Synthetic data generated for this project; no third-party license
applies. Team names/divisions are factual, publicly known information
about NFL league structure.

## Fields

| File | Key Fields |
|---|---|
| `teams.csv` | id, name, abbreviation, conference, division |
| `players.csv` | id, name, position, team_id, age, height_in, weight_lb, experience, status |
| `player_stats.csv` | id, player_id, season, games, games_started, stats_json (position-specific dict; see `app/analytics/position_tables.py` for the documented key list per position) |
| `contracts.csv` | id, player_id, years_remaining, annual_value ($M), guaranteed_money ($M), cap_hit ($M), contract_status |
| `draft_picks.csv` | id, year, round, overall_pick (null = future/unresolved), original_team_id, current_team_id |

## Transformations

`scripts/seed_demo_data.py` uppercases/trims position codes, parses the
`stats_json` column back into a dict, and loads rows into PostgreSQL. It
then computes and persists one `PlayerValuation` snapshot per player and
one `estimated_value` per draft pick using the analytics engines in
`backend/app/analytics/`.

## Known Limitations

- Statistics are **not** real season performance and must never be
  treated as such.
- Contracts do not reflect real cap mechanics (proration, void years,
  option bonuses, etc.) — see `docs/limitations.md`.
- The dataset intentionally skews toward a plausible distribution of
  player quality (via a Beta distribution) rather than reproducing any
  real league's talent distribution.

## Replacing With Real Data

To use a licensed/real dataset instead, replace these CSVs (or point
`scripts/seed_demo_data.py` at a different loader) with data matching the
same column layout, and set `DEMO_MODE=false` in `.env`. No frontend or
API changes are required, per the ingestion/analytics separation described
in `docs/architecture.md`.
